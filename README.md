# Hire-Hub — Full-Stack Job Portal

Hire-Hub is a job portal connecting job seekers with recruiters.

## Features
- Applicant and recruiter registration and login
- Search and browse jobs
- View job details
- Recruiters can post, edit, and delete jobs
- Applicants can apply with cover letters
- Recruiters can manage applications
- Applicants can track application status

## Technologies Used
- Frontend: React, Vite, JavaScript, CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT

## How to Run

### Frontend
```bash
npm install
npm run dev
```

### Backend
Open another terminal:

```bash
cd server
npm install
node server.js
```

Configure your MongoDB connection and JWT secret in `server/.env` before starting the backend.
